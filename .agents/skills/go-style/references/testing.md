# Tests

Rules — AGENTS.md §10. Default level: unit tests in `domain` +
integration tests on the endpoints. Mocks — mockery only.

## Unit: domain, table-driven

```go
package domain

import "testing"

func TestNewProfile(t *testing.T) {
	t.Parallel()

	tests := []struct {
		name    string
		age     int
		wantErr bool
	}{
		{name: "valid", age: 25, wantErr: false},
		{name: "age too low", age: 17, wantErr: true},
		{name: "empty name", age: 25, wantErr: true},
	}

	for _, tt := range tests {
		tt := tt

		t.Run(tt.name, func(t *testing.T) {
			t.Parallel()

			_, err := NewProfile(tt.name, tt.age, "a@b.ru", "+70000000000")
			if (err != nil) != tt.wantErr {
				t.Fatalf("NewProfile() error = %v, wantErr %v", err, tt.wantErr)
			}
		})
	}
}
```

- Test name — lowercase words separated by spaces: `valid`, `age too low`.
- Cases come from the invariants (validate tags) — not "star wars" values.
- Only domain behavior is tested, without usecase (AGENTS.md §10).

## Integration: test/integration + testify suite

```go
//go:build integration

package test

import (
	"context"
	"testing"

	"github.com/stretchr/testify/require"
	"github.com/stretchr/testify/suite"
)

var ctx = context.Background()

func Test_Integration(t *testing.T) {
	suite.Run(t, &Suite{})
}

type Suite struct {
	suite.Suite
	*require.Assertions
	client *client.Client // generated API client of the service
}

func (s *Suite) SetupSuite() {
	s.Assertions = s.Require()
	s.ResetMigrations() // migrations down/up before the run
}

func (s *Suite) TestCreateProfile() {
	s.Require().NoError(nil) // scenario: create → get → update → delete
}
```

- One file per endpoint: `create_profile_test.go`, `get_profile_test.go`.
- Requires running infrastructure (the command comes from the repository's commands
  file, AGENTS.md §10).
- Requests go through the generated HTTP API client, not through internal packages —
  the whole contract is tested.

## Mocks

- Generated by mockery from `.mockery.yml` by the repository's generation command;
  never written by hand. A new port method → `//go:generate mockery` → regeneration.
- Usease unit tests (when written) use only these mocks.

## Running

- Only with commands from the repository's `Makefile`/`Justfile` (AGENTS.md §0);
  target names are never invented. Canonical: `test` = `go test -v -cover ./...`,
  `integration-test` = `go test -count=1 -v -tags=integration ./test/integration`.
